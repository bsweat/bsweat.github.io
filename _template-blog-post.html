Blog Post Template

Use this when adding a new object to the posts array in blog.html. The current highest post id is 7, so the next one should usually be 8.

How To Add A Post

step_01 Open blog.html.

step_02 Find const posts = [.

step_03 Paste the filled object immediately after the opening bracket so the newest post appears first.

step_04 Increment id, keep tags space-separated, and use the examples below for tagHTML.

Template Object

{
  id: 8,
  date: 'Jul 2026',
  title: 'Your Post Title Here',
  excerpt: 'One or two readable sentences shown on the blog index. Keep this under roughly 160 characters.',
  tags: 'security',
  tagHTML: '<span class="tag security">Security</span><span class="tag">HomeLab</span>',
  kicker: '// Category / Subcategory',
  body: `
    <div class="note"><strong>// Note:</strong> Optional callout text goes here.</div>

    <h2>Section Heading</h2>
    <p>Paragraph text goes here. Use <em>emphasis</em> for important terms.</p>

    <h2>Commands</h2>
    <pre>nmap -sV -sC --open &lt;TARGET_IP&gt;</pre>

    <h2>Takeaways</h2>
    <ul>
      <li>First point</li>
      <li>Second point</li>
    </ul>
  `,
},

Quick Reference

Filter tags: security, ctf, tools, general. Combine with spaces, like ctf security.

Visible tags: Security CTF HomeLab OSINT

Code blocks: use <pre>...</pre>. They now render as smaller terminal-green text on black.

// Reminder: The body field is a backtick string. If you need a literal backtick inside it, escape it as \`.
