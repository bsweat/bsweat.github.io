Template Object

{
  status: "wip",
  name: "Your Project Name",
  desc: "One or two sentences describing what the project does, the problem it solves, and what makes it useful.",
  stack: [
    { label: "Python", hi: true },
    { label: "Nmap", hi: false },
    { label: "Security", hi: false },
  ],
  link: { text: "github ->", href: "https://github.com/bsweat/your-repo" },
},

Quick Reference

Status values: active wip done

Stack tags: set hi: true on the main language/tool and hi: false on the rest. Keep it to about 3-4 tags.

Links: common button text is github ->, view ->, demo ->, or writeup ->. Use # for drafts.
